## ✨ 复习：三样法宝合体

今天不学新概念，把学过的串成一条龙：

> **变量**（存住方块）→ **Touched 事件**（碰到）→ **函数**（把要做的事打包）

我们就在 AUTHORING 那段经典结构上，往函数里多放几件事。

<StudioStep n={1} title="先搭好经典结构">
  打开 `MagicFloor` 里的 Script，确认（没有就补上）这段：

```lua
local part = script.Parent

local function onTouch(hit)
	part.BrickColor = BrickColor.Random()
end

part.Touched:Connect(onTouch)
```
</StudioStep>

<StudioStep n={2} title="往包裹里加“消失”">
  在 `onTouch` 里，变色那行**下面**再加两行，让它被踩到后消失、还能被穿过。顺手给每行加上**注释**（`--` 后面的字），帮你记住每行在干嘛：

```lua
local part = script.Parent                        -- 找到我住的那块地板

local function onTouch(hit)                       -- 碰到时要做的事，全打包进来
	part.BrickColor = BrickColor.Random()         -- 先随机换一种颜色
	part.Transparency = 1                         -- 再变透明，看不见了
	part.CanCollide = false                       -- 也不再挡人，能穿过去
end                                               -- 包裹到这里装完

part.Touched:Connect(onTouch)                     -- 碰到就打开这个包裹
```

  - `part.Transparency = 1`：变全透明，看不见了。
  - `part.CanCollide = false`：不再挡人，玩家能直接穿过去。
</StudioStep>
