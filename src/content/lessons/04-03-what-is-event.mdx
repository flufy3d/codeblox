## 🎯 今天要做什么

今天不写很多代码，先搞懂一个超重要的词：**事件（Event）**。懂了它，下一课我们就能让方块“被碰一下就有反应”！

## ✨ 新知识：事件 = “发生某件事 → 就做某事”

生活里到处都是事件：

- **门铃响了 → 就去开门**
- **闹钟响了 → 就起床**
- **有人踩到地雷 → 就爆炸** 💥

游戏里也一样。Roblox 里有很多事件，今天认识最有用的一个：

> **Touched（碰到）**：当**有东西碰到这个方块**时，就触发。

也就是说：

> 有人/有东西碰到方块（发生某件事）→ 我们让方块变色、消失……（就做某事）

下一课我们就把“做某事”写成代码，让魔法地板真的动起来。

<StudioStep n={1} title="放一块“魔法地板”">
  **主页 → 部件**，把它压扁一点当地板。
</StudioStep>

<Shot id="4.3-s1" capture="视口里一块压扁的方形地板平铺在灰色地面上，占画面正中" alt="一块压扁的方块，就是我们的“魔法地板”" />

<StudioStep n={2} title="起个名字">
  在右边**属性**面板里找到 **Name** 那一行，把值改成 `MagicFloor`（魔法地板）。这样我们一眼就知道它是干嘛的。（也可以在资源管理器里点中它，按 **F2** 或右键 → **重命名**。）
</StudioStep>

<Shot id="4.3-s2" capture="属性面板「数据」分类里的 Name 一行，值是 MagicFloor，红框框住这行" alt="属性面板里的 Name 改成了 MagicFloor" />

<StudioStep n={3} title="先放好一个脚本">
  在资源管理器里**右键 MagicFloor → 插入 → 插入对象… → 搜 Script**，先留着空的，下一课我们往里写 Touched。
</StudioStep>

<Shot id="4.3-s3" capture="资源管理器里 Script 缩在 MagicFloor 下面一格，红框框住这两行" alt="MagicFloor 里装着一个空 Script，就等下一课了" />

## 🕹️ 看看你的成果

你已经懂了“事件”这个大概念，还准备好了一块叫 `MagicFloor` 的地板和一个空脚本。**下一课，碰一下它就会有反应！** 🔔
