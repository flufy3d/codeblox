## 🎯 今天要做什么

把你辛苦做出来的游戏，从“只存在这台电脑里”升级成“存在 Roblox 云端”。这样就算换台电脑、或电脑出了问题，你的作品也丢不了——它跟着你的账号走。

## ✨ 新知识：本地保存 vs 云端保存

想象你画了一幅画：

- **本地保存（文件 → 保存到文件…）** = 把画放进自己书桌的抽屉里。只有坐在这张书桌前才拿得到，抽屉坏了画也就没了。
- **云端保存（文件 → 保存至 Roblox）** = 把画寄存到一个超级安全的大仓库，凭你的账号随时随地都能取回来。

两个都要做：平时随手存到文件，做出阶段成果就「保存至 Roblox」存一份到云端。

<Shot id="8.1-s1" capture="Studio 文件菜单展开，两个红框分别框住「保存到文件...」和「保存至 Roblox」两行" alt="同一个菜单里的两件事：上面那个存进电脑，下面那个存上云" />

<Callout type="warning">
  ⌨️ **别把 Ctrl + S 当成“存到电脑”**：在 Studio 里按 Ctrl + S，弹出来的是**「保存体验」**窗口——那是**存到云端**。想存到自己电脑，要走 **文件 → 保存到文件…**。
</Callout>

<Callout type="info">
  小提示：Roblox 对**不同年龄段**的账号，能不能公开发布、能不能社交，规定是不一样的。今天我们只做“存档到自己的云端”，还不涉及公开。具体能开哪些功能，以**家长账号控制台**和当时的**官方政策**为准——家长可以在控制台里管理孩子的发布与社交权限。
</Callout>

<StudioStep n={1} title="先本地存一次">
  点左上角的 **文件** 菜单 → **保存到文件…**，给文件起个名存到自己电脑上。这一步保证你眼前的进度先不丢。
</StudioStep>

<StudioStep n={2} title="再打开「保存至 Roblox」">
  还是 **文件** 菜单，这次点 **保存至 Roblox**（快捷键就是 **Ctrl + S**）。
</StudioStep>

<StudioStep n={3} title="填名字和描述">
  弹出来的窗口叫 **保存体验**。给作品起个**名字**（比如“我的障碍跑酷”），下面那个大框写一句**描述**。再下面的“创作者”“设备”先不用动。这一步还不是发布，别人看不到。
</StudioStep>

<Shot id="8.1-s2" capture="「保存体验」窗口上半部分，红框框住 名称 输入框和 描述 输入框，里面已经填了“我的障碍跑酷”和一句描述" alt="给你的作品起个名字，再写一句描述" />

<Callout type="warning">
  👨‍👩‍👧 **家长看一眼这个窗口的下半部分**：往下拉，「保存体验」里还有 **组队创作** 和 **数据分享** 两个开关，**默认都是开着的**（数据分享的说明写着“此体验的数据将用于训练 Roblox Gen AI 模型”）。不想开就在点保存之前把它们关掉——之后在 **文件 → 体验设置** 里随时能再改。
</Callout>

<Shot id="8.1-s3" capture="「保存体验」窗口下半部分，红框框住 组队创作 和 数据分享 两个绿色开关，右下角能看到 保存 按钮" alt="这两个开关默认是开着的（绿色）——和家长一起决定要不要关" />

<StudioStep n={4} title="点「保存」上传">
  点右下角的 **保存**，等它传完（几秒钟）。传完会出现一句绿色的 **保存成功！**，下面写着“你可以在 我的障碍跑酷 中找到此场景”。Studio 最上面那行标题也从 `Place1` 变成了你起的名字。
</StudioStep>

<Shot id="8.1-s4" capture="保存完成后的窗口：一张缩略图、作品名字、红框框住绿色的“保存成功！”" alt="看到这句绿字，就说明你的作品已经在云端了" />

<Callout type="info">
  🏷️ Roblox 把你的作品叫做**体验（Experience）**，一个体验里可以装好几个**场景**。所以窗口上会写“在 我的障碍跑酷 中找到此场景”——意思就是“存好了，放在你那个体验里”。
</Callout>

<StudioStep n={5} title="验证一下">
  关掉 Studio 再重新打开，在起始页左边点 **体验**（首页上的“我的近期体验”里也能看到），应该能找到刚才那个名字，卡片上还写着修改时间。点开它，作品原封不动回来了！
</StudioStep>

<Shot id="8.1-s5" capture="Studio 起始页的「体验」页，左边红框框住导航里的「体验」，右边红框框住那张作品卡片上的 🔒 私人 标记和名字" alt="起始页左边点「体验」，你的作品就在这儿——卡片上那个小锁表示现在是“私人”" />

## 🕹️ 看看你的成果

你的游戏现在有了两个“家”：一个在你电脑里，一个在 Roblox 云端。从今往后，重要进度记得两边都存。

还有一件好事：卡片上那个 **🔒 私人** 说明它**一上传就是锁着的**——除了你，谁都进不去。第 3 课我们会去确认这把锁。

<Callout type="warning">
  如果没成功？
  - **点「保存至 Roblox」没反应**：确认你已经**登录了自己的 Roblox 账号**（右上角应显示头像）；没登录就只能存到文件。
  - **「体验」里看不到**：可能上传还没传完，或登录的是另一个账号。等网络好一点，重新 文件 → 保存至 Roblox 再存一次。
</Callout>
