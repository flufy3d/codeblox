## 🎯 今天要做什么

让方块**不再只是方块**！把它变成圆柱当柱子、变成球当装饰，再用数字精确控制大小——搭出传送门拱门的**两根柱子**。

## ✨ 新知识：Shape（形状）和 Size（大小）

一个 Part 不只有方块一种样子。在 Properties 里有两个好用的属性：

- **Shape（形状）**：可以选 **Block（方块）/ Ball（球）/ Cylinder（圆柱）**，一个 Part 想变啥变啥。
- **Size（大小）**：用 **三个数字** 精确决定 **长、宽、高**。想要又细又高的柱子？把“高”那个数字调大就行。

不用拖手柄一点点猜，直接打数字最精确。🔵

<StudioStep n={1} title="把方块变成圆柱">
  放一个 Part，在 Properties 里找到 **Shape**，选 **Cylinder（圆柱）**。
  <Shot id="2.3-s1" capture="Properties 里 Shape 下拉菜单展开，能看到 Block / Ball / Cylinder 三项，框出 Cylinder" alt="Shape 下拉里有方块、球、圆柱三种形状" />
</StudioStep>

<StudioStep n={2} title="拉成一根柱子">
  在 **Size** 里把 **X** 调大（比如改成 12），圆柱就变长了；再用 **Rotate（旋转）** 把它竖起来，就是一根高高的柱子。
  <Shot id="2.3-s2" capture="Properties 里 Size 展开成 X / Y / Z 三个数字、X 已改成 12 的样子，用箭头指一下 X（圆柱的长度在 X 上，见下面的提示）" alt="Size 的三个数字就是长、宽、高，圆柱的长度是「X」" />
</StudioStep>

<StudioStep n={3} title="复制出第二根">
  选中柱子，**Ctrl + C** 复制、**Ctrl + V** 粘贴，再用 **Move** 把它移到左边。两根一样高的柱子左右摆开。
</StudioStep>

<StudioStep n={4} title="加一个圆球装饰">
  再放一个 Part，把 **Shape** 改成 **Ball（球）**，放到一根柱子顶上当装饰。
</StudioStep>

<Callout type="tip">
  改 Size 时，三个数字旁边写着 **X、Y、Z**。**方块**想长高就调 **Y**。

  不过**圆柱是个例外**：它的两个圆面朝着 **X** 的方向，所以圆柱的“长度”在 **X** 上——调 Y 只会让它变成一块胖胖的圆饼 🥞。而且圆柱刚放出来是**躺着**的，把 X 拉长之后还要用 **Rotate（旋转）** 把它竖起来，才是一根柱子。
</Callout>
