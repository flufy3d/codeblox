## 🎯 今天要做什么

你的游戏发布了，现在最重要的一件事是：**弄清楚谁能玩它**。

好消息先说：**新发布的游戏，Roblox 默认就把它锁成“私人”了**——上一课你在起始页看到的那个 🔒 就是证据。所以今天不是“去上锁”，而是**去亲眼确认这把锁，并且学会它在哪儿**。这一课请**一定和家长一起做**。

## ✨ 新知识：公开 vs 私人

把你的游戏想成你的房间：

- **私人（Private）** = 房间门锁着。只有你自己进得来；想让谁进，得你一个一个请进来。
- **公开（Public）** = 房间门大开，还挂在了街上的地图上。**任何人**——包括你完全不认识的陌生人——都可能走进来。

设置里那三个按钮是 **私人 / 受限 / 公开**。中间的“受限”和右边的“公开”都会让你不认识的人有机会进来，**我们只用最左边那个：私人**。

<Callout type="info">
  🧭 **这个开关不在 Studio 里**。Studio 的 **文件 → 体验设置** 只管名字、聊天、安全那些；点到最后一项**其他设置**，它自己写着“有关其他设置，请参见创作者中心”，还给了一条**受众 > 访问权限**的链接。所以“谁能玩”这件事，必须去**网站**上做。
</Callout>

<Callout type="warning">
  **家长须知（请家长读）：**
  隐私设置一定要**家长在场、和孩子一起操作**。Roblox 现在的选项是 **私人 / 受限 / 公开**，新体验**默认是私人**——请保持这个状态，不要让孩子单独改成公开。一旦“公开”，陌生人就可能搜到这个游戏、进入，并可能尝试与孩子互动。请同时在**家长账号控制台**里检查孩子账号的发布与社交权限——不同年龄段开放的功能不同，以当时**官方政策**为准。
</Callout>

<StudioStep n={1} title="家长一起打开创作者中心">
  和家长一起打开浏览器，输入 **create.roblox.com**（注意：是**网站**，不是 Studio），用你的账号登录。这个网站叫**创作者中心**。
</StudioStep>

<StudioStep n={2} title="在「作品」里找到你的游戏">
  左边点 **作品**，右边就是你所有的作品。找到上一课发布的那个名字——卡片上应该写着 **🔒 私人**。看到这个小锁，说明门是锁着的。
</StudioStep>

<Shot id="8.3-s2" capture="创作者中心「作品」页，只有那张示范作品的卡片，红框框住卡片上的 🔒 私人 标记" alt="创作者中心的「作品」页——卡片上写着 🔒 私人 就说明锁着" />

<StudioStep n={3} title="点开它 → 配置 → 设置">
  点卡片的名字进去。左边一列里点 **配置**，再点下面的 **设置**（页面标题会变成**内容设置**）。
</StudioStep>

<Shot id="8.3-s3" capture="创作者中心的「内容设置」页，两个红框分别框住左边导航里高亮的「设置」和顶上面包屑里的「作品」" alt="点开作品 → 左边 配置 → 设置，就到了「内容设置」" />

<StudioStep n={4} title="往下拉，找到「受众」">
  在这一页**往下拉**，找到 **受众**（下面写着“选择谁可以在此体验发布后游玩”）。确认被选中的是左边那个 **私人**——它下面会有一行说明：“只有所有者和拥有编辑权限的人才能游玩这个体验。”
</StudioStep>

<Shot id="8.3-s4" capture="创作者中心「受众」那一块：私人 / 受限 / 公开 三个按钮，红框框住选中的「私人」，下面能看到那行说明文字" alt="三个按钮里选最左边的「私人」——下面那行字就是它的意思" />

<StudioStep n={5} title="改动过就保存">
  如果它原来**不是**私人，就点一下 **私人**，然后拉到页面最下面点 **保存更改**。**不点保存就等于没改**。没改动过的话，这个按钮是灰的——那就什么都不用做，锁本来就是好的。
</StudioStep>

## 🕹️ 看看你的成果

现在你**亲眼确认**过了：你的游戏门是锁着的，陌生人搜不到、进不来。

这一步是整套课程里**最重要的安全习惯**——发布之后第一件事，永远是先确认受众是“私人”。

<Callout type="warning">
  如果没成功 / 拿不准？
  - **找不到「受众」**：它在“内容设置”页的**下半部分**，要往下拉；上面是名称、描述和主题。
  - **网页不是中文**：拉到页面最下面，右下角有个地球图标可以切换到**中文(简体)**。
  - **拿不准选哪个**：拿不准时，**永远选更私密的那个**。公开这件事，必须和家长充分商量后再说。
</Callout>
