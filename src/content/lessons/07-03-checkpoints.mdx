## 🎯 今天要做什么

给 Obby 加上**检查点**：玩家走到这里，就**存了一次档**——后面就算掉下去，也只**从这个检查点重来**，不用从头再爬一遍！🏳️ 这是跑酷游戏里最贴心的设计。

## ✨ 新知识：检查点也是一块“重生点”

上节课我们认识了 SpawnLocation。其实**每个玩家**身上都记着一个“我下次从哪出生”，叫做 **RespawnLocation（重生位置）**。

检查点的魔法很简单：当玩家**碰到**一块检查点，我们就把他的 RespawnLocation **改成这块检查点**：

```lua
player.RespawnLocation = checkpoint
```

<Callout type="warning">
  **这里有个非做不可的规矩：检查点必须也是一块 SpawnLocation，不能是普通的 Part。**
  RespawnLocation 只认 SpawnLocation，塞一块普通 Part 进去，Output 会立刻红字报错：
  `Expected SpawnLocation got Part for Player.RespawnLocation`。
</Callout>

## ✨ 新知识：先关着，碰到才打开

上节课说过：**启用着的重生点，Roblox 会随便挑一个**让玩家出生。检查点也是重生点，要是就这么放着，你一进游戏可能直接出现在关卡中段——白闯了。

所以检查点脚本的第一行先把它**关掉**，等玩家真的碰到了再**打开**：

```lua
local checkpoint = script.Parent
checkpoint.Enabled = false   -- 先关着，不然会随机出生在这儿

checkpoint.Touched:Connect(function(hit)
	local player = game.Players:GetPlayerFromCharacter(hit.Parent)
	if player then
		checkpoint.Enabled = true   -- 碰到了，正式启用
		player.RespawnLocation = checkpoint   -- 下次从这儿重来
		print(player.Name .. " 到达检查点！")
	end
end)
```

怎么知道是“哪个玩家”碰到的？还记得第 6 单元学的吗——用 **Touched** 拿到 `hit`，再用 **GetPlayerFromCharacter** 找出玩家。一模一样的老朋友。

<Callout type="info">
  这段脚本放在**检查点这块 SpawnLocation 里面**（`script.Parent` 就是检查点自己）。复制这个检查点时，脚本会一起被复制——所以一块做好，就能复制出好几个检查点！
</Callout>

  在资源管理器里**右键 `Workspace` → 插入 → 插入对象…**，在搜索框里打 `SpawnLocation`，点它一下就插进来了。
  （**主页 → 部件** 那个下拉里只有方块、球体这些**形状**，没有 SpawnLocation，别在那儿找。）
</StudioStep>

## 🕹️ 看看你的成果

一条**带存档点**的路：走得越远，重来的起点越靠前。玩家再也不怕摔一次就前功尽弃了！下一节，我们给路上加一个**会动的障碍**，让闯关更刺激。

<Callout type="warning">
  摔下去还是回到最起点？三件事挨个查：检查点是不是 **SpawnLocation**（不是普通 Part）、脚本是不是放在**检查点里面**、代码里 `Enabled` 有没有在碰到时改成 `true`（一直关着的重生点是不生效的）。
</Callout>
